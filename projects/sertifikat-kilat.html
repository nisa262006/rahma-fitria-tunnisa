02 / THE PROBLEM

Repetitive & Manual Certificate Generation

Penyelenggara acara, organisasi mahasiswa, dan institusi kerap membutuhkan ratusan hingga ribuan sertifikat digital bagi peserta event. Pembuatan secara manual satu per satu sangat menyita waktu, rentan terhadap salah ketik nama, dan tidak memiliki validasi keaslian dokumen.

03 / MY ROLE & RESPONSIBILITIES

Workflow Architecture & Web Interface

Sebagai Web & System Developer, kontribusi saya meliputi:

  • ▸ Workflow Mapping: Merancang alur pemrosesan dari unggah spreadsheet hingga pengunduhan PDF.
  • ▸ Front-end Web UI: Membangun antarmuka landing page dan halaman pencarian sertifikat.
  • ▸ Integrasi QR Engine: Membantu penempatan QR Code unik untuk validasi keabsahan sertifikat.
