02 / THE PROBLEM

Manual Administrative Bottleneck

Sebelum sistem ini dibangun, seluruh kegiatan operasional administrasi Yayasan Sahabat Quran Bogor — termasuk pencatatan biodata santri, pendaftaran calon santri baru, dan penyusunan laporan keuangan — dilakukan secara manual.

Proses pencatatan manual ini memerlukan waktu pemrosesan dan verifikasi data yang lama (mencapai hingga 1 minggu) serta memiliki risiko tinggi terjadinya pembungkusan data ganda atau ketidaksesuaian laporan keuangan.

03 / MY ROLE & RESPONSIBILITIES

Backend Architecture & Database Design

Saya berperan sebagai Backend Developer dalam tim pengembang inti 3 orang (1 Project Manager, 1 UI/UX & Frontend Developer, 1 Backend Developer).

Tanggung jawab utama saya meliputi:

  • ▸ Relasi Database: Merancang skema tabel SQL untuk registrasi, data santri, dan transaksi keuangan.
  • ▸ Backend Logic: Membangun logika autentikasi login pengguna dan alur validasi formulir santri.
  • ▸ Integrasi Data: Menghubungkan antarmuka frontend dengan query basis data agar pemrosesan berjalan real-time.
  • ▸ Requirement Gathering: Ikut serta mendengarkan kebutuhan pengurus yayasan saat pengumpulan spesifikasi.
